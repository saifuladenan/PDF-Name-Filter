#  PDF Name Filter

##Description:

- **PDF Name Filter is a simple yet effective tool designed to help you filter and organize PDF files from a large collection based on a list of filenames provided in a text file. It efficiently scans through a pile of PDF files, compares each file's name to the entries in your provided list, and moves the matching PDFs into a designated folder. This tool is perfect for organizing large repositories of PDF files quickly and with minimal effort.

##Features:
- **File Filtering: Compares a list of filenames from a text file against a large collection of PDFs.
- **Automated Movement: Automatically moves matching PDF files from one directory to another.
- **Efficient: Quickly processes large sets of files without manual sorting.
- **Simple Setup: Just provide a list of filenames and a source directory, and let the script do the rest.
